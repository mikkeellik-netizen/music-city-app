# Озвучка заданий (Подготовка + 1 класс) — ЗАРЕЗЕРВИРОВАНО НА БУДУЩЕЕ

> Пока это **только место под будущую интеграцию**. Кода озвучки ещё нет —
> задания работают без голоса. Здесь зафиксирован контракт, чтобы при
> подключении не пришлось трогать контент уроков.

## Зачем

Дети 4–6 лет (Подготовка и 1 класс) могут ещё не уметь читать. Поэтому
**каждое задание этих уровней должно озвучиваться**: вопрос, варианты
ответа и реакция на верный/неверный ответ. Голос — мягкий, глубокий,
спокойный, русский.

## Главный принцип: тексты УЖЕ в данных

Ничего дублировать не нужно. Текст для голоса берётся из полей задания,
которые уже заполняются в `src/content/prep/*.js` и `src/content/grade1/*.js`:

| Что озвучиваем | Откуда берём текст |
|---|---|
| Вопрос / инструкция | `task.prompt` (у `teach` — `task.body`) |
| Каждый вариант ответа | `task.opts[].label` |
| Верный ответ | `task.fbOk` |
| Неверный ответ | `task.fbNo` |

Поэтому при интеграции **контент-файлы уроков не меняются**. Достаточно
одной точки подключения (диспетчер озвучки + пробросить пару колбэков в
`G1Runner`).

## Два возможных источника звука (решаем при интеграции)

1. **Готовые MP3** — студийная запись, файлы кладутся сюда:
   - `public/audio/prep/<stationId>-<taskIndex>-<slot>.mp3`
   - `public/audio/grade1/<stationId>-<taskIndex>-<slot>.mp3`
   - где `slot` ∈ `q` (вопрос) · `opt-<v>` (вариант, `<v>` = `opts[].v`) ·
     `ok` (верно) · `no` (неверно).
   - Пример: `prep/pd1s1-1-q.mp3`, `prep/pd1s1-1-opt-yes.mp3`,
     `prep/pd1s1-1-ok.mp3`.
   - Плюс: офлайн (PWA), нулевая задержка, гарантированное качество голоса.
   - ⚠️ Путь завязан на **индекс задания в станции** — если позже
     вставлять/переставлять задания, для MP3-пути надёжнее добавить в задание
     явный стабильный `vid` (voice id) и строить путь от него. Для TTS это
     не нужно.

2. **API TTS на лету** (ElevenLabs / Yandex SpeechKit) — синтез из тех же
   текстовых полей, с кэшем результата.
   - Плюс: нулевые правки данных, новый текст озвучивается автоматически.
   - Минус: нужен интернет и ключ на бэкенде; небольшая задержка.

Оба пути читают один и тот же текст — выбор источника не влияет на контент
уроков и переключается в одном месте.

## Точка подключения (когда дойдём)

- Диспетчер `Voice.play(text | audioPath)` — рядом с
  `src/content/prep/prep-sounds.js` (или отдельный `src/core/voice.js`).
- В `G1Runner` (`src/grade1/mc-g1d1-engine.jsx`): авто-озвучка `prompt` при
  показе задания, кнопка 🔊 у каждого варианта, озвучка `fbOk`/`fbNo` в
  момент показа реакции. Движок общий для Подготовки и 1 класса — правка в
  одном месте покрывает оба уровня.
